# Competitor review
This week I reviewed the Parker parking-information and payment journey in Pécs. The review considered map coverage, zone legends, local hours and prices, SMS eligibility, empty states, and the hand-off to external maps.

The main design points are to explain unknown map areas, pair colour with text labels, clarify payment eligibility, and make information sources easier to verify. One reported local price/hour mismatch has not been independently confirmed.
