# Problem definition and opportunity
This week I defined the target user, problem statement, user story, and opportunity areas for the parking-information concept.

The selected direction is to show the parking-area type, eligibility, restrictions, and relevant conditions before presenting payment. Unknown or conflicting information should not be treated as permission to park.
