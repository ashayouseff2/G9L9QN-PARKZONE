# Usability testing and UI guideline
Three participants reviewed the clickable prototype. Feedback was generally positive; comments also highlighted some complexity and the importance of official, trustworthy parking information.

The feedback is qualitative. Formal task-completion times, individual success rates, help requests, and confidence scores were not recorded. The UI guideline covers the colour palette, typography, spacing, visible focus, and status information that does not rely on colour alone.
