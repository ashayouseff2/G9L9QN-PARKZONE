# ZonePark — UX/UI Design Project

ZonePark is a parking-information concept for drivers in unfamiliar areas. It focuses on helping drivers understand parking-area type, eligibility, restrictions, operating hours, price and the next action before leaving the car. The initial project context is Hungary.

## Repository structure

- `homework/01/`–`homework/09/` — weekly homework documentation
- `presentation/01-01/` — final presentation and handout
- `project/` — project overview and supporting documentation
- `prototype/` — browser demonstration
- `figma-source/` — links and screen inventory for the original Figma work

The browser demonstration uses illustrative parking details. It is not connected to live municipal data, geocoding or a payment service. Always follow current official signs and parking-authority information.
