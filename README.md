# ZonePark — UX Design Project

ZonePark is a parking-information concept designed to help drivers understand parking areas, eligibility, restrictions, operating hours and prices before leaving their car.

## Project files

- `homework/` — Homework 01–09
- `presentation/` — Final presentation
- `prototype/` — Browser prototype
- `figma-source/` — Links to the original Figma files and screen overview

## Prototype

Open `prototype/index.html` in a browser to try the main screens and interactions. The displayed parking details are examples; the prototype is not connected to live municipal data or a payment service.
