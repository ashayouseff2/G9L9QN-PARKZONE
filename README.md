# ZonePark — UX Design Project

This repository contains the complete UX Design coursework package: Homework 01–09, the final 10-slide presentation, and the browser prototype.

## Contents
- `homework/` — coursework 01–09
- `presentation/` — final 10-slide presentation (Markdown transcription)
- `prototype/` — runnable browser prototype
- `figma-source/` — source links and inventory

## Project
ZonePark helps drivers understand parking area type, eligibility, restrictions, hours, price and next action before leaving the car.

**Important:** Prototype data is illustrative. This is not a live parking-data service and does not process payments. Follow official signs and parking authority information.
